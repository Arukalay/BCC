# Эталон дефектов (ручной разбор `docs/requirements.md`)

Агенту эталон не передаётся. Нужен для сверки отчёта (`python tests/compare_reference.py ...`).
Несколько цитат в одной ячейке разделены ` // `, дефект считается найденным, если в отчёте есть любая из них.

**Тип:** `внутри требования` — дефект виден в одном месте текста (промпт проверки одного требования); `набор` — противоречие между пунктами, пробел, нарушение шаблона, несогласованность терминов (промпт проверки набора).

**Нумерация стабильна.** Номера D-NN не сдвигаем. Новые дефекты добавляем в конец, ошибочные помечаем в тексте, а не удаляем.
